Common questions

Does compression affect the quality of responses?

Headroom uses semantic compression — it removes redundant tokens while preserving meaning. In benchmarks, compressed contexts produce responses indistinguishable from full-context responses.

Which LLM providers does it work with?

Any provider that accepts the OpenAI message format — OpenAI, Anthropic, Mistral, Groq, Together AI, and more. The proxy mode currently wraps OpenAI directly; compress mode works with any provider.

How is usage counted?

We count tokens going into the compression endpoint (tokens_in). You're billed on what you compress, not what you save — the savings are yours to keep.

Can I self-host instead?

Yes — Headroom is fully open-source at github.com/chopratejas/headroom. We're the hosted version for teams who'd rather not manage infrastructure.
